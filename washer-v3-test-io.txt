================================================================
  washer-v3-test 项目 IO 口分配表
  固件版本: 3-1.0.3-2026.8.21
  芯片:     ESP32-S3 (esp32-s3-devkitc-1)
  整理日期: 2026-08-21
================================================================

一、通信接口
----------------------------------------------------------------
[以太网 W5500 - SPI]
  GPIO13  SCLK    时钟         输出
  GPIO11  MOSI    主出从入     输出
  GPIO12  MISO    主入从出     输入
  GPIO14  CS      片选         输出
  GPIO10  INT     中断         输入
  GPIO9   RST     复位         输出

[I2C - iic_bus, 200kHz]
  GPIO41  SDA     数据线       I/O
  GPIO42  SCL     时钟线       输出

[UART]
  uart_debug (115200)
    GPIO43  TX    输出
    GPIO44  RX    输入
  uart_1 (9600, Modbus 主站)
    GPIO1   TX    输出
    GPIO2   RX    输入
  uart_2 (9600, 洗车机控制)
    GPIO20  TX    输出
    GPIO19  RX    输入

二、传感器
----------------------------------------------------------------
  GPIO4   ADC           DC power voltage (24V 经 100K/10K 分压)
  GPIO36  脉冲计数      105-风扇转速
  GPIO3   脉冲计数      103-入水流速
  GPIO8   脉冲计数      104-出水流速
  GPIO46  DHT           温湿度 (Temperature/Humidity)

三、开关量输入 (binary_sensor)
----------------------------------------------------------------
  GPIO5   01-外接电源
  GPIO45  02-漏水检测
  GPIO15  03-软水箱水位
  GPIO16  04-水箱水位
  GPIO21  05-洗车机蓝色灯
  GPIO47  06-洗车机绿色灯
  GPIO7   07-洗车机红色灯
  GPIO38  08-紧急按钮
  GPIO39  09-启动/停止
  GPIO18  10-车辆超高
  GPIO35  11-缺泡泡液
  GPIO17  12-门磁

四、输出
----------------------------------------------------------------
  GPIO6   树莓派复位 (switch, 点动高电平 500ms 后自动回低)
  GPIO37  200-风扇控制 (LEDC PWM 25000Hz)
  GPIO40  WS2812 灯 "Light id" (internal)
  GPIO48  WS2812 灯 "LED_on_board"
  GPIO0   运行指示灯 "sys run led" (status_led)

六、注意事项
----------------------------------------------------------------
- strapping pin (GPIO0/3/45/46): 上电瞬间电平影响启动模式, 外部电路需注意。
- PSRAM 冲突 (GPIO35/36/37): 在 ESP32-S3R8/R8V 型号上与 PSRAM 接口复用, 已产生编译警告。
- USB-Serial-JTAG (GPIO19/20): 与 USB-Serial-JTAG 复用, 作为普通 GPIO 有冲突警告。
- GPIO4 ADC 已设 attenuation: 11db, 量程约 0~3.1V。
