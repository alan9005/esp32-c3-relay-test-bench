# ESP32-C3 16 路继电器控制板测试台

基于 [ESPHome](https://esphome.io/) 的 **16 路继电器控制板**（Modbus RTU 从站）测试与集成环境。

使用 **ESP32-C3** 作为 Modbus 主站，通过 **RS485 总线**控制继电器板卡的 16 路输出，并提供**网页控制面板**，用于：

- 继电器模块的**功能测试**（单路开关、延时动作、自检）
- 继电器模块的**性能测试**（循环开关、次数 / 时长 / 间隔可设）
- 把该继电器模块**接入实际应用**（参考寄存器表直接对接任意上位机 / PLC）

> 网页控制面板支持 **中文 / English 双语切换**。

---

## 一、硬件组成与接线

| 部件 | 说明 |
|------|------|
| 主控 | ESP32-C3 开发板（Generic ESP32-C3，esp-idf 框架） |
| 受控设备 | 16 路继电器控制板（Modbus RTU **从站**，默认地址 **100**） |
| 通信 | RS485，默认 **9600 8N1**（可改 19200 / 38400 / 57600 / 115200） |

**接线示意（ESP32-C3 ↔ 继电器板卡）：**

| ESP32-C3 | 继电器板卡 |
|----------|------------|
| GPIO21 | RS485 TX |
| GPIO20 | RS485 RX |
| GND | GND |

> 如果你的 RS485 收发器需要方向控制（DE/RE），请按硬件补充 `flow_control_pin` 配置。

---

## 二、功能特性

- 16 路继电器**独立开关** + **一键全开 / 全关**
- 继电器**延时动作**（吸合后按设定时间自动释放，寄存器 400~415）
- **吸合延时**设置（寄存器 202，μs，掉电保存）
- **上电状态模式**设置（寄存器 204：全关 / 全开 / 恢复断电前状态）
- 继电器**延时自检**（寄存器 999，吸合 / 释放时间自学习）
- **性能测试**：选定继电器循环开关，可设次数、持续时长、翻转间隔
- 状态实时显示：固件版本、交流电源周期、吸合延时、直流电流、上电模式、配置索引
- 网络状态 LED 指示（常亮=已连接 / 慢闪=连接中 / 快闪=AP 配网）
- 网页控制面板，中英文可切换

## 四、快速开始

### 1. 安装 ESPHome

```bash
pip install esphome
# 或使用官方 Docker 镜像 / ESPHome Dashboard
```

### 2. 配置 WiFi

```bash
cp secrets.example.yaml secrets.yaml
```

编辑 `secrets.yaml`，填入你的 WiFi 名称和密码：

```yaml
wifi_ssid: "你的WiFi名称"
wifi_password: "你的WiFi密码"
```

> `secrets.yaml` 已被 `.gitignore` 排除，不会提交到仓库。

### 3. 检查配置

```bash
esphome config my-iot-relay-c3-demo.yaml
```

### 4. 编译烧录

```bash
esphome run my-iot-relay-c3-demo.yaml
```

首次烧录建议通过 USB 连接开发板；之后可通过 OTA 或网页上的「固件升级」上传。

### 5. 访问网页控制面板

设备连上 WiFi 后，浏览器访问 `http://<设备IP>/`（IP 会在启动日志 / 网页中显示）。

若首次未能连上 WiFi，设备会进入 AP 配网模式（热点：`relay-c3-demo Fallback Hotspot`）。

## 六、模块寄存器速查

完整说明见 [继电器控制板-485接口说明.md](继电器控制板-485接口说明.md)。

**写寄存器（功能码 0x06）：**

| 地址 | 功能 |
|------|------|
| 0 ~ 15 | 单路继电器开关（0=关 / 1=开） |
| 400 ~ 415 | 继电器延时动作（值 × 0.1s 后自动释放） |
| 51 | 设置波特率（1/3/4/6/7） |
| 52 | 全部继电器开关（0=全关 / 1=全开） |
| 202 | 吸合延时（μs，≤21666，掉电保存） |
| 204 | 上电状态模式（0/1/2） |
| 999 | 继电器延时自检 |

**读寄存器（功能码 0x03 / 0x04）：**

| 地址 | 内容 |
|------|------|
| 0 ~ 15 | 继电器状态 |
| 200 | 固件版本 |
| 201 | 交流电源周期（μs） |
| 202 | 吸合延时（μs） |
| 203 | 直流电源电流（mA） |
| 204 | 上电状态模式 |
| 205 | 配置存储区索引 |

## 七、融入实际应用

该继电器板卡是标准 **Modbus RTU 从站**，不依赖本项目即可被任何上位机接入：

1. **接入现有 PLC / 工控系统**：按寄存器表用功能码 0x06 写继电器、0x03 读状态即可。
2. **接入 Home Assistant**：将 `my-iot-relay-c3-demo.yaml` 中的实体（switch / sensor / select / button）直接同步到 Home Assistant，作为智能家居执行器使用。
3. **接入自建物联网网关**：直接按寄存器表读写继电器，即可集成进任意网关 / 主控逻辑。
4. **自定义前端**：`web/relay_dashboard.js` 通过 ESPHome 的 REST API 与 SSE 通信，可按需改造为自己的 UI。

## 八、常见问题

- **改模块波特率后连不上**：ESP 与模块波特率不一致。用网页「参数设置 → ESP 485 波特率」把 ESP 切到模块当前波特率，再把模块改回，或两边统一。
- **全部关闭按钮无效果**：已改为直接下发全关命令（写寄存器 52=0），不依赖开关状态。
- **状态不刷新**：模块不支持连续读多个寄存器，读取均为逐个单寄存器读。
