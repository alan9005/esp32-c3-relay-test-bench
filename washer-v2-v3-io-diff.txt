一、差异总览
----------------------------------------------------------------
  对比 GPIO 总数     : 36 个
  功能未变化        : 31 个
  功能发生变化      :  5 个  (GPIO4 / GPIO5 / GPIO6 / GPIO7 / GPIO48)

二、发生变化的 GPIO 明细
----------------------------------------------------------------
  GPIO4   v2 外接电源状态(二进制输入, 上拉)
          v3 ADC 电源电压检测(24V 经 100K/10K 分压, attenuation 11db)

  GPIO5   v2 WS2812 灯带1 (LED_strip_1, 60颗)
          v3 01-外接电源(二进制输入)

  GPIO6   v2 WS2812 灯带2 (LED_strip_2, 60颗)
          v3 树莓派复位(switch, 点动高电平 500ms 后自动回低)

  GPIO7   v2 WS2812 灯带3 (LED_strip_3, 60颗)
          v3 07-洗车机红色灯检测(二进制输入)

  GPIO48  v2 洗车机红灯检测(二进制输入, 上拉+反转)
          v3 WS2812 灯 "LED_on_board"(板载, internal)

三、按功能视角归纳
----------------------------------------------------------------
  [移除] 3 路 WS2812 灯带:
         GPIO5 / GPIO6 / GPIO7 (LED_strip_1/2/3, 各 60 颗 LED)

  [新增] 树莓派复位开关:
         GPIO6 (switch, 点动高电平 500ms 自动回低)

  [新增] ADC 电源电压检测:
         GPIO4 (24V 经 100K/10K 分压, attenuation 11db, 量程约 0~3.1V)

  [新增] 板载 WS2812 灯 LED_on_board:
         GPIO48

  [迁移] 外接电源检测:
         GPIO4 → GPIO5 (保持二进制输入)

  [迁移] 洗车机红色灯检测:
         GPIO48 → GPIO7 (保持二进制输入)

六、注意事项
----------------------------------------------------------------
- GPIO5/6/7 原为 WS2812 灯带输出，v3 改为 GPIO5 外接电源输入、
  GPIO6 树莓派复位输出、GPIO7 洗车机红色灯输入，硬件方向由输出变为
  输入/开关，接线与外部驱动电路需相应调整。
- GPIO48 原为洗车机红色灯检测输入，v3 改为 WS2812 板载灯输出。
- GPIO4 原为外接电源二进制检测，v3 改为 ADC 电压检测，需确认分压电路
  (100K/10K) 与 attenuation 配置一致。
- 洗车机红色灯检测从 GPIO48 迁移至 GPIO7；外接电源检测从 GPIO4 迁移至
  GPIO5，相关 YAML 配置与传感器 ID 需同步更新。
