water-ctrl-board.yaml IO 端口整理
========================================

一、UART 串口
----------------------------------------
1. UART debug
   - TX: GPIO43
   - RX: GPIO44
   - 波特率: 115200
   - RX 缓冲: 256

2. UART uart_1
   - TX: GPIO20
   - RX: GPIO19
   - 波特率: 9600

二、ADC 模拟输入（sensor）
----------------------------------------
1. GPIO4  -> DC power voltage
   - 衰减: 11db
   - 滤波: multiply 11
   - 更新间隔: 6s

三、GPIO 输出（switch，均 inverted: true）
----------------------------------------
1. GPIO7  -> GATE_ALL
2. GPIO15 -> GATE_A
3. GPIO16 -> GATE_B
4. GPIO17 -> GATE_C
5. GPIO18 -> GATE_D

四、GPIO 输入（binary_sensor，均 pullup + inverted）
----------------------------------------
1. GPIO14 -> WATER_1_TOP
2. GPIO13 -> WATER_1_BOTTOM
3. GPIO12 -> WATER_2_TOP
4. GPIO11 -> WATER_2_BOTTOM
5. GPIO10 -> WATER_3_TOP
6. GPIO9  -> WATER_3_BOTTOM
7. GPIO21 -> WATER_4_TOP
8. GPIO47 -> WATER_4_BOTTOM

五、GPIO 使用汇总（按引脚号排序）
----------------------------------------
GPIO4   | ADC      | DC power voltage
GPIO7   | 输出     | GATE_ALL
GPIO9   | 输入     | WATER_3_BOTTOM
GPIO10  | 输入     | WATER_3_TOP
GPIO11  | 输入     | WATER_2_BOTTOM
GPIO12  | 输入     | WATER_2_TOP
GPIO13  | 输入     | WATER_1_BOTTOM
GPIO14  | 输入     | WATER_1_TOP
GPIO15  | 输出     | GATE_A
GPIO16  | 输出     | GATE_B
GPIO17  | 输出     | GATE_C
GPIO18  | 输出     | GATE_D
GPIO19  | UART RX  | uart_1 (9600)
GPIO20  | UART TX  | uart_1 (9600)
GPIO21  | 输入     | WATER_4_TOP
GPIO43  | UART TX  | debug (115200)
GPIO44  | UART RX  | debug (115200)
GPIO47  | 输入     | WATER_4_BOTTOM

六、统计
----------------------------------------
- UART 引脚: 4 个（GPIO19/20/43/44）
- ADC 引脚:  1 个（GPIO4）
- 输出引脚:  5 个（GPIO7/15/16/17/18）
- 输入引脚:  8 个（GPIO9~14、GPIO21、GPIO47）
- 合计使用: 18 个 GPIO
